Recitune プライバシーポリシー

2026年10月30日 制定

このプライバシーポリシーは、レシピ管理アプリ「Recitune」（以下「本アプリ」）が、利用者の情報をどのように扱うかを説明するものです。

ポイント

  • レシピ・買い物リスト・設定は、あなたの端末（とあなた自身の iCloud）に保存されます。運営者には送られません。
  • 運営者は、利用者の個人情報を収集せず、販売もしません。
  • 動画情報の取得と広告の表示のために、YouTube・TikTok・Google などの外部サービスと通信します。

1. マイクと音声認識

本アプリは、調理モードで「次へ」「戻る」などの声による操作を行うために、マイクと音声認識を使います。マイクと音声認識は、利用者が許可した場合にだけ、調理モードで声の操作を使っている間に利用します。

音声認識は、できる限り端末の中で処理します。端末の中で処理できない場合は、音声認識のために音声データが Apple のサーバーに送られ、処理される可能性があります。この処理は Apple のプライバシーポリシーに従って行われます。運営者が音声を録音・保存したり、受け取ったりすることはありません。

マイクと音声認識の許可は、iPhone の「設定」→「プライバシーとセキュリティ」からいつでも取り消せます。

2. 端末内に保存するデータ

利用者が保存したレシピ、買い物リスト、アプリの設定は、利用者の端末の中に保存されます。運営者がこれらのデータを受け取ることはありません。

3. iCloud バックアップ

「iCloudにバックアップ」がオンのときは、レシピと買い物リストが利用者自身の iCloud アカウントに保存されます。このデータは Apple のサービス上で利用者のアカウントに保存されるもので、運営者が閲覧することはできません。

4. 動画情報の取得（YouTube・TikTok など）

利用者がレシピ動画のURLを貼り付けたとき、動画のタイトル、サムネイル画像のURL、概要欄・説明文などの公開されている情報を取得するために、本アプリはその URL をもとに次のサービスと通信します。

  • YouTube：YouTube Data API などの YouTube API サービスを利用します。本アプリを利用することで、利用者は YouTube 利用規約 に同意したものとみなされます。YouTube API サービスの利用については YouTube API サービス利用規約 を、Google による情報の扱いについては Google プライバシーポリシー をご覧ください。
  • TikTok：TikTok が公開している仕組みを使って、動画の情報を取得します。

このほか、利用者が Instagram・クックパッド・楽天レシピのURLを貼り付けたときは、公開されている説明文やページに書かれた料理名・材料・手順を読み取るために、それぞれのサイトと通信します。

これらの通信では、取得したい動画やページのURLが各サービスに送られます。また、通信の性質上、端末の IP アドレスなどが各サービスに伝わることがあります。各サービスでの情報の扱いは、それぞれのプライバシーポリシーに従います。

5. 写真・スクリーンショットの文字の読み取り

利用者が選んだ写真やスクリーンショットに含まれる文字は、端末の中で読み取ります。写真や読み取った文字が運営者や外部のサーバーに送られることはありません。

6. 広告（Google AdMob）

本アプリは、広告の配信に Google が提供する Google AdMob を使っています。広告の配信のために、端末の広告識別子（IDFA）、IPアドレス、端末やアプリの情報、広告の表示やタップの状況などが、Google によって収集される場合があります。

広告識別子は、利用者が App Tracking Transparency の確認でトラッキングを許可した場合にだけ利用されます。許可しない場合は、利用者の興味に合わせない広告が表示されます。許可は iPhone の「設定」→「プライバシーとセキュリティ」→「トラッキング」からいつでも変更できます。

Google による情報の扱いについては、Google プライバシーポリシー と Google のサービスを使用するサイトやアプリから収集した情報の Google による使用 をご覧ください。

広告非表示プランをご利用中は、広告は表示されません。

7. App 内課金

広告非表示プランなどの App 内課金の支払いは、Apple が App Store を通じて処理します。運営者が、利用者のクレジットカード番号などのお支払い情報を受け取ることはありません。

8. 個人情報の収集・販売について

運営者は、利用者の氏名、メールアドレス、位置情報などの個人情報を収集しません。また、利用者の個人情報を第三者に販売することはありません。

ただし、お問い合わせをいただいた場合は、返信のために、いただいたメールアドレスとお問い合わせの内容を使います。これらはお問い合わせへの対応以外には使いません。

9. このポリシーの変更

運営者は、必要に応じてこのプライバシーポリシーを変更することがあります。変更したときは、このページでお知らせします。
